# PLaylist Message Converter

The goal of this project was to probe that I could automated a long amount of characters (The message in question) with 2 consecutives top of use inside spotify structure as well as the summition of images together to create a large sectioned paragraph for my friend, it was a detail that I thought it could be great to document for possible recruiters that need something similar.

## Status

Still in progress.

## Setup

You'll need to create most of the ground for this app so it can work for you. Everything that need some organization was already made but the Spotify account as well as the setup of ports and images and more you need to work with it, locations, contents and the details of the output. I left a referral example in the project.

## Tech stack

- Python 3
- Spotify Web API (OAuth 2.0 Authorization Code Flow)
- "spotipy", "Pillow", "python-dotenv"
